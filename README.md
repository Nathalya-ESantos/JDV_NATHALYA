# ❌⭕ Jogo da Velha (React + Vite) - Refatoração React

Projeto desenvolvido para a disciplina de Desenvolvimento de Sistemas. O objetivo principal é refatorar e evoluir a aplicação clássica do tutorial oficial do React, transformando-a em uma aplicação moderna, modular, acessível e visualmente aprimorada.

---

## 🎯 Objetivo do Projeto
- **Refatoração Estrutural:** Transformar o código base em uma arquitetura modular baseada em componentes funcionais.
- **Design & Interface:** Criar um *Design System* utilizando **CSS Modules** (com nomenclatura BEM) integrado com **Bootstrap** para layout e responsividade.
- **Boas Práticas:** Aplicar princípios de *Clean Code*, imutabilidade no manuseio de estados no React (`useState`), acessibilidade HTML semântica e organização limpa de arquivos.

---

## 🛠️ Tecnologias Utilizadas
- **[React](https://react.dev/)** (Componentização, Hooks: `useState`, `useEffect`)
- **[Vite](https://vitejs.dev/)** (Build tool e ambiente de desenvolvimento rápido)
- **[CSS Modules](https://github.com/css-modules/css-modules)** (Estilização escopada e modular)
- **[Bootstrap](https://getbootstrap.com/)** (Sistema de Grid e layout responsivo)
- **JavaScript (ES6+)** e **HTML5 / CSS3**

## 🚀 Como Baixar e Executar o Projeto Localmente

### Pré-requisitos
Certifique-se de ter instalado em sua máquina:
- [Node.js](https://nodejs.org/) (versão 18 ou superior)
- [Git](https://git-scm.com/)

### Passo a Passo

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/Nathalya-ESantos/JDV_NATHALYA.git

2. **Acessar a pasta do projeto:**
   ```bash
   cd nome-do-repositorio
   ```

3. **Instalar as dependências:**
   ```bash
   npm install
   ```

4. **Executar o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

5. **Acessar no navegador:**
   Abra o endereço exibido no terminal (geralmente `http://localhost:5173`).
